KIAN'S GAMING HUB

HOW TO OPEN (Windows 7)
1. Extract this ZIP file.
2. Open the Kian_Gaming_Hub folder.
3. Double-click index.html.
4. Click Games to open the game list.

MAIN GAMES INCLUDED
- GunVals (games/gunvals.html)
- Gojo: Cursed City (games/gojo-cursed-city.html)
- AlphaBlox Offline (games/alphablox-offline.html)
- AlphaBlox Online button opens the GitHub project page.

SPONSORS
- Roblox (external Roblox website link)
- Eaglercraft Offline (featured sponsor tile; its playable file was not included)

BUTTON SOUNDS
The site generates its own sounds in the browser. No extra audio downloads are required.
- Glassy Pop: normal button clicks
- Futuristic Swoosh: page/navigation clicks
- Soft ASMR: button/link hover
- Ultimate Mixture: highlighted/special buttons

NOTES
This is a local website. Internet access is needed for the external Roblox and GitHub links.
The AlphaBlox Offline file is the uploaded offline edition. The online button opens the AlphaBlox GitHub repository.
